## ✨ Key Features

- 🧠 Multiple puzzle types including Queens, Pinpoint, Logic Riddle, and Number Grid
- 📅 Daily puzzle sessions with streak tracking
- 🎯 Practice mode for focused skill development
- ⏱️ Challenge mode with timed gameplay
- 🗂️ Archive mode for replaying puzzle content
- 📊 Statistics and performance tracking
- 💡 Puzzle-specific hints and tutorials
- 🔊 Browser-based sound effects
- 📱 Mobile-first responsive interface
- 🎉 Animated feedback and completion effects
- 💾 Local browser persistence for player progress
- ⚡ Fast Vite-powered frontend
- 🧩 Feature-oriented React architecture

## 🎮 Game Modes

| Mode | Description |
|------|-------------|
| **Daily** | Solve the daily puzzle set and maintain your streak |
| **Practice** | Practice puzzles by type and difficulty |
| **Challenge** | Complete a timed, score-oriented puzzle run |
| **Archive** | Browse and replay the puzzle catalog |

---

## 🧩 Puzzle Types

| Puzzle | Description |
|--------|-------------|
| **Queens** | Place queens while satisfying row, column, region, and adjacency rules |
| **Pinpoint** | Identify the hidden connection between clue words |
| **Logic Riddle** | Solve short text-based riddles and logic problems |
| **Number Grid** | Complete missing numbers using logical patterns |

## 📱 Design Philosophy

Puzzlogic Game is designed around a simple principle:

> **Make short puzzle sessions feel rewarding enough to become a daily habit.**

The interface uses a clean mobile-first layout, focused gameplay cards, clear feedback, lightweight animations, and a simple navigation system so players can move from opening the app to solving a puzzle with minimal friction.
